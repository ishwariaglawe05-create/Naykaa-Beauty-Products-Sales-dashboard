# Nykaa Beauty Products – Sales Analysis Dashboard

## 📌 Project Overview

The **Nykaa Beauty Products Dashboard** is an Excel-based data analysis project designed to analyze sales performance and business insights for beauty and skincare products.

This project uses Microsoft Excel to organize sales data, analyze revenue and profit, compare product performance, and understand regional sales trends through dashboards and data summaries.

## 🎯 Project Objectives

- Analyze overall sales and revenue performance.
- Identify top-performing beauty products and categories.
- Compare sales and profit across different regions and cities.
- Analyze monthly and quarterly sales trends.
- Track units sold, discounts, and net revenue.
- Understand customer ratings, payment modes, and product returns.

## 🛠️ Tools & Technologies

- **Microsoft Excel**
- Pivot Tables
- Excel Formulas and Functions
- Data Analysis
- Dashboard Visualization
- Data Cleaning and Formatting

## 📂 Dataset Description

The dataset contains sales and transaction information related to beauty and skincare products.

Key columns include:

| Column | Description |
|---|---|
| Order ID | Unique order identifier |
| Date | Order date |
| Month, Quarter, Year | Time-based analysis |
| Category | Product category |
| Product Name | Name of the beauty product |
| Brand | Product brand |
| Channel | Sales channel |
| Region and City | Geographic sales information |
| Units Sold | Quantity sold |
| Unit Price (₹) | Price per unit |
| Revenue (₹) | Revenue generated |
| COGS (₹) | Cost of goods sold |
| Gross Profit (₹) | Profit before applicable deductions |
| Discount (₹) | Discount amount |
| Net Revenue (₹) | Revenue after discounts, as defined in the dataset |
| Rating | Product or customer rating |
| Payment Mode | Payment method |
| Return Flag | Indicates return status |

## 📊 Dashboard Features

- **Sales Performance:** Analyze revenue and units sold.
- **Profit Analysis:** Review gross profit and cost of goods sold.
- **Product Analysis:** Compare product and category performance.
- **Regional Analysis:** Explore sales across regions and cities.
- **Time-Based Analysis:** Review monthly and quarterly performance.
- **Customer Insights:** Examine ratings and return information.
- **Payment Analysis:** Compare different payment methods.

## 💡 Key Business Benefits

- Helps identify high-performing products.
- Supports sales and profit comparisons.
- Makes regional and time-based trends easier to understand.
- Helps businesses monitor discounts and returns.
- Supports data-driven business decisions.
